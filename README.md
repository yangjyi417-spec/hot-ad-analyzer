# 热点广告分析 · 技能工作台

把"刷热点"变成方法论：抓取多平台实时热点 → 按 12 个广告学维度自动拆解 → 一键生成可交互分析报告。

## 一分钟启动

前置：电脑装有 Node.js 18 及以上（本机已满足）。

1. 打开终端（PowerShell 或 CMD），进入本文件夹：
   ```
   cd 路径\hot-ad-analyzer
   ```
2. 启动服务：
   ```
   node server.js
   ```
3. 浏览器打开：**http://localhost:5178**

无需 `npm install`，纯 Node 实现，零依赖。

## 它能做什么

- **真实抓取**：服务端实时汇总五个数据源成「今日热点池」，带榜位、热度值、来源标签，可切换：
  - **全网热搜**（聚合数据跨平台热榜，含抖音 / 小红书等，40 条）
  - **微博热搜**（50 条）、**B站热门**（30 条）—— 这两个无需任何 key
  - **新闻榜单**（聚合数据头条新闻列表，30 条）
  - **AI简报**（聚合数据 AI 新闻简报，10 条，自带摘要，会把摘要作为分析上下文喂给大模型，拆解更贴合内容）

  抓取全部在服务端完成，规避浏览器跨域限制。三个聚合数据（juhe）源各自需要在 `config.json` 的 `juhe` 块里填对应接口 Key：`hotKey`（全网热搜）、`newsKey`（新闻列表）、`briefKey`（AI简报）。注意聚合数据的 Key 是按接口单独授权的，一个 Key 通常只能用它开通的那一个接口。
- **12 维拆解**：点任意热点（或手动粘贴标题），按传播 / 受众 / 创意 / 媒介 四大环节 × 各 3 维自动分析：
  传播—信源 / 扩散机制 / 生命周期；受众—画像 / 核心洞察 / 情绪触点；创意—品牌契合 / 创意角度 / 内容形式；媒介—媒介适配 / 时效窗口 / 风险合规。
- **借势指数**：按你定的权重「时效 > 风险 > 契合」加权算出 0–100 总分，首屏给一句话结论（建议快反 / 谨慎尝试 / 不建议借势）+ 红黄绿风险灯。
- **可交互报告**：顶部是完整不裁切的 12 维雷达图，下方把 12 个维度按传播 / 受众 / 创意 / 媒介 四大环节**整合成四段连贯正文**（悬停雷达轴会高亮对应段落）；再附创意建议、时效与风险清单、数据来源脚注，可"导出/打印"成 PDF。

## 每日归档与检索

- **自动存当天**：每次抓取都会把当日热点（含来源、日期、热度、摘要）自动写入 `data/archive/<日期>.json`，按 id 去重累积，不会重复堆叠。
- **历史归档视图**：点右上角「📅 历史归档」，可按**日期**（下拉列出有存档的每一天）、**分类**（全网热搜 / 新闻榜单 / AI简报 / 微博热搜 / B站热门）筛选，并支持标题/摘要/分类的**关键词搜索**。
- **分析缓存 · 秒开**：跑过大模型的热点会缓存到 `data/analyses.json`，同一条再次打开**瞬间出报告**（标题旁显示「⚡ 已缓存 · 秒开」），想重跑点「重新分析」即可绕过缓存。每条的分析也会挂到归档记录上，归档卡片标「✓已分析」。

> 提示：聚合数据（juhe）的免费额度里，AI简报接口每日可请求次数较少，测多了会当天超限返回"超过每日可允许请求次数"，次日自动恢复；工具对失败的源会单独标注、不影响其它源。

## 让它变聪明：填一个免费大模型 Key

刚启动时是**本地规则引擎模式**（右下角徽章显示"本地引擎模式"），它能把全流程跑通、给出中性基线，但 12 维的文字洞察是占位的。填入一个免费的智谱 GLM Key 后，拆解会升级为真正有依据的 AI 分析。

步骤：

1. 注册智谱 BigModel 开放平台（手机号即可，免信用卡），在控制台创建一个 API Key。它家 `glm-4-flash` 等 Flash 系列对个人免费。
2. 打开本文件夹里的 `config.json`，把 Key 粘进 `apiKey`：
   ```json
   {
     "port": 5178,
     "model": {
       "apiKey": "把你的KEY粘贴到这里",
       "model": "glm-4-flash",
       "baseUrl": "https://open.bigmodel.cn/api/paas/v4/chat/completions"
     }
   }
   ```
3. 重启 `node server.js`。徽章变成绿色"大模型已接入"即生效。

> 想换 DeepSeek 等更便宜的付费模型：把 `baseUrl` 改成 `https://api.deepseek.com/chat/completions`、`model` 改成 `deepseek-chat`、填对应 Key 即可（OpenAI 兼容端点都支持）。

## 文件结构

```
hot-ad-analyzer/
├─ server.js            后端：抓取代理 + 12维分析 + 借势指数 + 每日归档/缓存
├─ config.json          填大模型 Key 与聚合数据 Key 的地方（留空=本地引擎）
├─ README.md            本说明
├─ data/                运行时自动生成
│  ├─ archive/          每日热点快照 <日期>.json
│  └─ analyses.json     大模型分析结果缓存
└─ public/
   └─ index.html        前端单页（含手绘 SVG 雷达图，无外部依赖）
```

## 数据合规说明

只抓公开榜单与公开统计数字，不抓用户隐私、不绕过登录墙批量爬内容。报告引用的是热度指标。抓取有超时与容错；某平台被限频时，可稍后刷新或用"手动粘贴标题"兜底。

## 验证方式

浏览器地址栏访问 `http://localhost:5178/?demo=1` 可直接查看一份样例报告，确认渲染是否正常。
